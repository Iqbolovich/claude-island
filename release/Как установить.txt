Claude Island — виджет лимитов Claude в стиле Dynamic Island для Windows 10/11

1. Скачай последний ClaudeIsland_<версия>_x64-setup.exe со страницы Releases и запусти его.
   Если Windows пишет «Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае»
   (установщик просто не подписан платным сертификатом). Права администратора не нужны.

2. При первом запуске откроются настройки. Вставь ключ сессии claude.ai:
   браузер → claude.ai (войти) → F12 → Application → Cookies → https://claude.ai → значение sessionKey.
   Ключ хранится только на твоём компьютере, зашифрованным средствами Windows.
   Когда ключ устареет, остров напишет об этом — просто вставь новый.

3. Telegram (по желанию): в Telegram Desktop → Настройки → Уведомления и звуки включи
   «Уведомления на рабочем столе» и «Использовать уведомления Windows».

4. Музыка подхватывается сама — Spotify, Яндекс Музыка, браузер и любые плееры с карточкой трека в Windows.

5. Claude Code (по желанию): в настройках, раздел «Claude Code» → «Подключить».
   Тогда остров светится, пока Claude думает, вспыхивает зелёным, когда он закончил,
   и пульсирует янтарным, когда ждёт разрешения. Работает в новых сессиях Claude Code.

Горячая клавиша Win+Alt+C прячет и показывает остров (меняется в настройках).
Каждую функцию острова можно выключить в настройках, там же английский язык.

Настройки: значок в трее → «Настройки» или ⚙ в раскрытом острове.
Новые версии программа находит сама и предлагает обновиться (настройки → «Проверять обновления»).
Удаление: Параметры Windows → Приложения → Claude Island.
