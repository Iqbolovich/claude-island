Вход

Вход в claude.aiОткроется окно claude.ai — войди как обычно, ключ сохранится сам.
Вставить ключ вручную
  1. Открой claude.ai в браузере и войди.
  2. F12 → Application → Cookies → https://claude.ai.
  3. Скопируй значение sessionKey и вставь сюда.
Ключ хранится только на этом компьютере, зашифрованным средствами Windows.

Предупреждения

Claude Code

Остров покажет, когда Claude Code думает, закончил или ждёт разрешения. Работает в новых сессиях.

Telegram

Новые сообщения из Telegram Desktop — прямо на острове.

Проверка

Если сообщения Telegram не появляются
  1. Telegram Desktop → Настройки → Уведомления и звуки: включи «Уведомления на рабочем столе» и «Использовать уведомления Windows».
  2. Там же включи «Показывать текст сообщения», иначе в уведомлении будет только «Новое сообщение».
  3. Параметры Windows → Система → Уведомления: уведомления включены, Telegram в списке разрешён, режим «Не беспокоить» выключен.
  4. Параметры Windows → Конфиденциальность → Уведомления: доступ приложений к уведомлениям разрешён.
Даже без уведомлений остров покажет число непрочитанных — его видно в заголовке окна Telegram.
